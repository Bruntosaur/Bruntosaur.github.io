Project 0.2 — Raspberry pi controls

Through a rotary encoder and a LCD

Notes

Through a websocket this program reads the input of a rotary encoder that is connected to a raspberry pi. The data is made ready for its comparisson with the tidal data. The data is then sent back through the websocket to the raspberry pi to be displayed on an LCD.
