Lab 03 — Animation

A person climbing up a huge tree

Notes

Hold the left mouse button to pause the climber on its way up the bark of this enormous pine tree. You can move the climber around using the left and right arrow key. I've added overlaid backgrounds that move in slightly different speeds creating a parallax effect. Music: C418's Stal.
